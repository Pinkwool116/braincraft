**选择 "interrupt"**（中断并停下手头的事）：
- 玩家明确要求你停下来、过来、换一件事做
- 出现紧急情况需要你立即行动
- 玩家给了一个全新的任务，和你当前做的事不兼容

**选择 "chat"**（边做边回复，不停下来）：
- 只是闲聊、问候、聊天
- 玩家的消息不需要你改变当前行为
- 可以口头回应但手上的活不用停
